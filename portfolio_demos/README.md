# Portfolio demos

Marketing / case-study assets for the two portfolio projects. Not part of either
project's build — these live here so the project repos stay focused on their milestones.

| File | What it is |
|---|---|
| `grounded-doc-qa.html` | Case-study page for the Grounded Doc Q&A project (standalone, opens in a browser) |
| `lead-to-booked-agent.html` | Case-study page for the Lead-to-Booked Agent project |
| `canvas/*.dc.html` | Six UI mockup screens (3 per project), authored for the Claude Design canvas |
| `canvas/canvas.json` | Canvas layout for the six screens |

The mockup screens are also published as an interactive canvas with PNG/PDF export.
`canvas/product-demo-screens.html` is a generated bundle and is gitignored.
